Numerical Solutions of Thiele's ODE for Life Insurance

Course: MATH 0728 – Advanced Numerical Analysis

Project: Senior Numerical Analysis Project

Environment: MATLAB (Online or Desktop)

Description : This project compares explicit and implicit numerical methods for solving Thiele's differential equation for life insurance reserves.
The numerical methods investigated are: Explicit Euler method, Implicit trapezoidal method, Fourth-order Runge–Kutta method (RK4)
The project examines convergence, numerical error, stability, and computational efficiency under different mortality assumptions, including Gompertz's and Makeham's laws.

Repository Structure:
SRC/ – MATLAB functions implementing numerical methods and Thiele's ODE
Experiments/ – MATLAB scripts for numerical experiments
Results/ – Figures, tables, and numerical results
demo_results/ – Additional demonstration outputs

Goals: 
Implement three numerical methods for Thiele's ODE.
Compare convergence rates using different step sizes.
Investigate the influence of mortality assumptions.
Compare accuracy and computational cost.
